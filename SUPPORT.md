# Support

Rail Connector MCP is a community open-source project maintained on a best-
effort basis. There is no service-level agreement.

## Use GitHub Issues For

- Reproducible defects
- Supported-platform compatibility failures
- Documentation corrections
- Focused feature proposals

Include the OS, Node version, Claude Code version, Codex client, package version,
reproduction steps, expected behavior, and sanitized MCP status. Remove local
paths, usernames, titles, transcripts, Remote Control URLs, tokens, and session
identifiers.

## Do Not Use Public Issues For

- Security vulnerabilities; follow `SECURITY.md`
- Credentials, private logs, customer data, or live session links
- General Claude Code or Codex account support
- Guaranteed compatibility with unadvertised external CLI behavior

Terminal UI heuristics can require updates after external CLI releases. A clear
reproduction fixture is more useful than a screenshot containing private data.
