# Code of Conduct

Project spaces should be professional, constructive, and safe for technical
collaboration.

## Expected Behavior

- Discuss ideas and evidence without attacking people.
- Respect different experience levels and communication styles.
- Keep criticism specific, actionable, and relevant to the project.
- Protect private and sensitive information.
- Accept maintainer decisions and disengage when a discussion is closed.

Harassment, threats, discriminatory conduct, sexualized content, deliberate
disclosure of private information, spam, and sustained disruption are not
accepted.

## Enforcement

Maintainers may edit or remove content, lock discussions, reject contributions,
or restrict participation. For conduct that violates GitHub policy, use
GitHub's built-in abuse reporting. Do not post sensitive incident details in a
public issue. Once the repository is public, the private reporting channel in
`SECURITY.md` may also be used with the subject `Conduct report`.

Enforcement decisions will consider context, severity, impact, and prior
behavior. Retaliation against a good-faith reporter is prohibited.
